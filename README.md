# نظام الحضور والانصراف – فرع الجيزة

نسخة جديدة مستقلة من الصفر. لا تعتمد على قاعدة البيانات أو كود النسخة القديمة.

## المزايا
- كود الموظف فقط، بدون PIN.
- منع تكرار كود الموظف بشكل صحيح.
- إضافة وتعديل وتفعيل وتعطيل وحذف الموظفين.
- تسجيل حضور وانصراف مرة واحدة يوميًا لكل موظف.
- QR خاص بالفرع.
- تحقق GPS وGeofencing.
- لوحة إدارة وإحصائيات.
- تقارير مع تنزيل Excel.
- SQLite محلية داخل مجلد `data`.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

كلمة مرور الإدارة الافتراضية: `123456`

بعد الدخول: افتح **إعدادات الفرع** واضبط الإحداثيات ونطاق GPS، ثم أنشئ QR.
